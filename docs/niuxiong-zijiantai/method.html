不藏着。下面把四维打分、温度合成、仓位映射、三重硬约束、降级规则、数据字典全部摊开。所有锚点、权重与 compute.js 里的常量一一对应，可审计。

数据现状（不装实时）：宏观已接入 akshare 每日自动采集（29 字段中 11 个为真实值，其余保留基线并逐行标注）；温度与仓位已由真实数据驱动。回测序列 2015–2026-06 为首发静态回测（138 月），2026-10 起由管线按月自动追加（沪深300 日线口径，双成熟才落库）。公式同样全部可审计，各字段覆盖情况见 ⑤。

① 四维打分公式

四个维度各由若干指标锚点插值成 0–10 分（区间外 clamp 到端点），再按子权重合成。语义：分数越高越热、越危险。

双模型语义说明（防重复计分）：本表估值维＝贵热度（越贵分越高，服务温度计）；BBII 方向计取同一数据的反向（便宜度=10−贵热度）；情绪维在 BBII 中做倒U变换（狂热反扣）。共享 4 维在温度与 BBII 中各只计 1 次，且 BBII 不参与仓位计算——任一信号对最终仓位只影响一次。

② 温度合成

temp = 0.30 × trend + 0.30 × valuation + 0.20 × liquidity + 0.20 × sentiment  （保留 2 位小数）

标签：≤3 偏冷·结构性机会；3<temp<5 中性；5≤temp<7 偏热；≥7 过热·减仓。

④ 三重硬约束与保守系数

最终仓位 = round1( min(温度仓位 + 黄金坑Boost, 信用上限, 共振上限) × 保守系数 )
黄金坑Boost：主触发(PSI≥60 且 temp≤3) +2.0 成 ｜ 次触发(PSI≥70 且 temp≤4) +1.0 成 ｜ 其余 0

① 信用约束 creditCap

creditCap = mapScore(credit_yoy, [[6→3], [7→4.5], [8→6], [8.5→10]])  （社融收缩强压仓位）

② 共振约束 resonanceCap

trend≥7 且 valuation≥7 → 3 成（双热共振·牛顶减仓） trend≤3 且 valuation≤3 → 10 成（双冷共振·黄金坑，不约束） valuation≥7.5 且 sentiment≥8 → 4 成（估值情绪双极端） 其他 → 10 成（不约束）

④′ 黄金坑 Boost（PSI × 温度）

gpBoost = 2.0 若 PSI≥60 且 temp≤3（政策托+深超跌·历史+6.41%/命中75%）
gpBoost = 1.0 若 PSI≥70 且 temp≤4（政策底+超跌·历史+2.71%/命中61%）
gpBoost = 0 其余；且 PSI<50 且 temp≤4 时面板显示「下跌中继·勿盲加」告警

Boost 加在 min 之前：黄金坑是「极端便宜的加仓许可」，但仍受信用上限/共振上限/保守系数三重硬约束管辖，不突破既有安全绳。PSI 由六层话术 NLP 打分（L1字面词典/L2弦外沉默/L3言行印证/L5场合权重/L6制度固化），当月值随重大政策发言更新。

③ 保守系数 conservativeFactor

基线 1.0，每命中一条 −0.05，下限 0.80：  china_fragile≥8 / vix≥25 / hormuz_risk≥7 / win_proximity≥6 / 核心字段 asOf 超 45 天

⑤ 降级（标灰）规则

  1. 字段级：macro 某字段缺失 / asOf 超 90 天 → 使用内置基线值，明细表该行灰底 + 「基线」徽标，其维度子权重不变（用基线值照常计分），但触发保守系数的陈旧惩罚。
  2. 文件级：quotes.json 拉取失败时，先走腾讯 JSONP 兜底（浏览器直连 qt.gtimg.cn，与采集脚本同一解析口径）；兜底也失败 → 行情条用 macro 内 vix / amt_yi / oil_brent 等基线值渲染并整块标灰。
  3. 数据现状（不装实时）：macro.json 由 akshare 每日自动采集 11 个字段（PMI / M1 / M2 / LPR / 沪深300 PE 及 10 年分位 / PB 分位 / 两融 / 贸易帐 / 美国失业率 / 70 城二手房同比），其余 18 个字段仍为内置基线——明细表「来源」列逐个标注，标灰即基线，不用猜。
  4. 全站级：三文件全失败 → 渲染基线快照 + 顶部黄条「数据不可用，以下为基线值」，计算引擎照常跑，永远给得出一个仓位数字。
  5. 数据源级联（2026-10-20 实测教训）：东财 push2his 接口可能无预警断连 → 趋势源级联「东财 → akshare 新浪日线 → 沿用上次值」；VIX 级联「stooq → 本土 20 日已实现波动率代理」。任何兜底/代理值必须在来源列如实标注「沿用/代理」，绝不伪装成实时。

⑧ 牛熊强度 BBII（方向计·仅解读）与黄金坑反向加仓

温度是「风险计」（越高越热→越降仓），BBII 是「方向计」（越高越牛，仅作牛熊解读、不参与仓位计算）。两表共享 4 维原始数据、各只计 1 次，不存在重复计分。

BBII 公式（0–100，权重和=100）

BBII = 0.25×PSI + 0.20×趋势 + 0.15×估值(便宜度) + 0.15×流动性 + 0.12×盈利 + 0.08×资金 + 0.05×情绪(倒U)

共享4维取自①的同一数据：趋势/流动性原值×10；估值取便宜度 = 10 − 贵热度；情绪做倒U变换（6分为乐观峰值，狂热反扣）。独有3维：政策PSI（六层话术NLP，138月序列已回测：救市94/924=99/严监管27–30/托而不举75–81）、盈利基本面、资金流向。

⑦ 局限性与免责

温度是「现在大概在哪个季节」的归纳，不预测明天涨跌；历史回测用的是事后统计口径，实时仓位只用当日可得数据，不存在未来函数。模型在极端行情、政策突变、数据停更时可能失效。

补充诚实边界（2026-10-20）：PSI（政策托举力）的方向预测力≈0（Pearson −0.035，强托举月命中 51%）——它精准划分政策 regime，但不能预测涨跌，故仅作黄金坑触发器与方向解读；黄金坑信号样本 n=16/18 偏小，阈值 60–65 为稳健平台期（PSI≥80 失效），需随每月新数据滚动复验；展示层已去重（BBII 面板不重画共享维卡片）。

本面板为个人投资研究的公开分享，所有内容仅供参考与学习，不构成任何投资建议或要约。市场有风险，投资须独立决策，盈亏自负。过往表现不代表未来，模型在极端行情下亦可能失效。
