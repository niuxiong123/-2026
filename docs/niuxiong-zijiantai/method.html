仓位与板块，怎么用

这个页面用大白话讲清两件事，帮你判断「钱该怎么摆」：① 大盘仓位——现在该拿多少股票、留多少现金（每天更新的「方案C·股债比价」）；② 板块选择——同样一笔钱，往哪些行业 / ETF 板块偏（下方「板块量化看板」，用十年回测选出的最靠谱方法）。两件事互补：仓位管「拿多少」，板块管「往哪放」。下面的内容都是个人研究分享，不是投资建议。

数据说明（不装实时）：宏观数据由 GitHub Actions 每日自动采集（部分字段为真实值，部分为基线值并逐行标注）；板块看板为定期更新的静态快照。所有「今日具体数字」以首页实时数据为准，本页只讲方法，不写死数值。

一、大盘仓位怎么定（方案C · 股债比价）

大白话：不猜「明天涨不涨」，只比「股票和债券，谁更便宜」。算一个比值 R（沪深300全收益 ÷ 一个以债券为主的「债腿」），再把 R 放到 2007 年至今的全样本里排个历史分位——分位越低，股票越便宜，越该多拿；分位越高，越该收手。

四道安全锁（层层往下拧，最后取最保守的一档）：

  • 阶梯档位：按 R 分位给满仓 / 高 / 中 / 低 / 空五档；用「双阈值滞回」防抖——市场小幅震荡时不会一天满仓一天空仓地乱跳。
  • 凯利微调：用过去约 3 年实际波动，波动大时自动收一收，防止「一把梭」。
  • 股债双杀熔断：股票、债券 20 日同时大跌，说明可能是流动性危机，直接压到 20 成，先活下来。

看哪里：今日具体仓位由 GitHub Actions 写入 stockbond.json，在首页「当前执行档位」实时展示，本页不写死。

单位提醒（务必看清）：本站「成」= 百分点。100 成 = 满仓（100%），50 成 = 半仓（50%），显示保留两位小数。它不是旧式「一成 = 10%」——50.00 成就是半仓，不是 5%。

二、板块量化看板（下方嵌入 · 十年回测选出的最靠谱方法）

大白话：用 A 股三轮牛市（2014–2015 / 2019–2021 / 2024–至今）共 241 个时点的「留一交叉回测」，从 9 套因子方案里选出最能提前认出领涨板块的那一套，再用它给 36 只 ETF 打分组：买进 / 持有 / 卖出。它管的是「往哪放」，和上面的仓位（「拿多少」）配合用。

怎么读这张看板（通俗版）

  • 买进 / 加仓：当前信号偏强，可纳入观察或建仓候选。
  • 持有：信号中性，拿着就行。
  • 卖出 / 减仓：信号转弱，考虑落袋。
  • 灯号（宏观闸门）：🔴 红 = 暂停新增买进（观察期总仓 ≤ 30%）；🟡 黄 = 谨慎（≤ 45%）；🟢 绿 = 可积极（≤ 45%）。
  • 仓位尺子：单只 ETF 别超过总仓的 12%；红闸时新建仓 = 0%，先把现有仓位管好。

最优解（回测说了算，不靠拍脑袋）

  • 主干用「D · 九因子等权」——十年回测 Top1 命中 2/3（9 套里最高）、高分组超额 +0.468（最高），是最稳的。
  • 「H · 半动态权重」 AUC 与 D 并列第一，但 Top1 和超额略低，作为第二意见并列展示，不取代 D。
  • 当前宏观为 🔴 红闸，所有「买进」信号已自动降级为「观察」，不急着动手——这正是闸门的用意。

三、务必知道的风险

  • 这是归纳，不是预言：模型告诉你「历史上类似情况后多半怎么走」，不预测明天涨跌。
  • 会失效：极端行情、政策突变、数据停更时，模型可能失灵。
  • 没有未来函数：回测用事后统计口径，实时只用当日可得数据。
  • 个人分享：仅供参考与学习，不是投资建议或要约；市场有风险，决策请独立判断，盈亏自负。过往表现不代表未来。

▸ 技术原理（想深究可展开 · 公开可审计）

下面是从 2026-10-25 起保留的方法细节，便于审计与回溯。日常阅读不需要看这一节。

① 温度模型（历史方法 · 仅供参考，现行执行已切换为方案C）

四维（趋势 / 估值 / 流动性 / 情绪）各由若干指标锚点插值成 0–10 分，再按 0.30 / 0.30 / 0.20 / 0.20 合成「温度」；温度越高越热、越该降仓（≤3 偏冷、3–5 中性、5–7 偏热、≥7 过热）。该模型自 2026-10-24 起已降级为历史方法与解读参考，不再作为执行依据。

② 方案C · 股债比价四约束链（现行执行口径）

核心：R = 沪深300全收益 ÷ 债腿（中证全债×80% + 沪深300全收益×20%，按月再平衡 + 终点校准 5.03）；全样本分位自 2007-01 起算。四条约束依次下拧，最终仓位取最保守的一档：① 滞回阶梯（满/高/中/低/空，双阈值防抖，单一真源 hyst_core.py）；② 动态 Kelly 微调（插值 μ/λ + 滚动 σ 156 周 + cn10y）；③ 股债双杀熔断（股20日≤−5% 且 债20日≤−1% → 压到 20 成）。诚实局限：债腿是有意偏乐观的假设（让 R 整体偏「股更便宜」），分位样本含指数成分调整偏差。

③ 降级 / 兜底规则（万一数据断了怎么办）

  1. 字段级：某字段缺失 / 超过 90 天 → 用内置基线值，明细表该行灰底 + 「基线」徽标，并触发保守系数的陈旧惩罚。
  2. 文件级：行情拉取失败 → 先走腾讯 JSONP 兜底（浏览器直连 qt.gtimg.cn）；兜底也失败 → 行情条用基线值渲染并整块标灰。
  3. 全站级：三文件全失败 → 渲染基线快照 + 顶部黄条提示，计算引擎照常跑，永远给得出一个仓位数字。
  4. 数据源级联：东财接口可能无预警断连 → 趋势源级联「东财 → akshare 新浪日线 → 沿用上次值」；任何兜底 / 代理值必须在来源列如实标注，绝不伪装成实时。

④ 保守系数（已接入的触发）

基线 1.0，每命中一条 −0.05，下限 0.80：china_fragile≥8 / vix≥25（已接入代码）。注：原文档还列有 hormuz_risk≥7 / win_proximity≥6 / 核心字段 asOf 超 45 天 三条，目前为规划项、尚未接入计算代码——此处以实际代码为准，不夸大。
